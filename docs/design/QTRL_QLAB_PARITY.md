# Qtrl ↔ QLab 5: функционал (сверка)

Цель: Qtrl делает всё, что делает QLab 5 для звука и управления шоу, с тем же расположением, сочетаниями клавиш и
поведением. Источник — документация QLab 5 (qlab.app/docs/v5) и опыт работы с QLab; из этой среды сайт qlab.app
недоступен, поэтому пункты, где поведение QLab восстановлено по памяти, помечены «⚠ сверить».

Статус: ✅ есть · 🟡 частично · ❌ нет · ➖ вне области (видео/свет — решение владельца).

## Рабочее окно

| QLab 5 | Qtrl | Что сделать |
|---|---|---|
| GO, «Standing by» с заметками, Pause/Resume all, Panic | ✅ | — |
| Список кью: №, имя, цель, пауза до, действие, пауза после, продолжение | 🟡 | колонка «Цель»; правка значения прямо в строке (двойной щелчок / N Q E D W) |
| Боковая панель Lists · Carts · Active | 🟡 | Carts как отдельные сетки кью (сейчас — банки one-shot) |
| Инспектор снизу, вкладки по типу кью | ✅ | вкладки Triggers, Levels, Trim, Effects (см. ниже) |
| Режимы Edit / Show | ✅ | Show: блокировка playhead по желанию |
| Строка состояния: предупреждения, число кью, настройки | 🟡 | число кью и «сломанных» кью |
| Сочетания клавиш QLab | 🟡 | ⌘T «Load to time», ⚠ сверить полный список |
| Поиск кью (⌘F), переход к кью (⌘J) | 🟡 | ⌘F |
| Цвета, флаги, заметки | 🟡 | флаг кью |

## Кью

| Тип QLab 5 | Qtrl | Что сделать |
|---|---|---|
| Audio | ✅ | срезы (slices) с повторами, ganged levels, Audio Effects (AU), trim, pitch при rate |
| Mic | ❌ | живой вход с маршрутизацией и уровнями |
| Video / Camera / Text | ➖ | решение владельца |
| Light | ➖ | (свет — через OSC-кью) |
| Fade | 🟡 | ✅ абсолютный / относительный, кривые, «стоп цели по окончании»; осталось: фейд скорости и панорамы |
| Network (OSC) | ✅ | шаблоны QLab-сообщений, UDP/TCP |
| MIDI, MIDI File, Timecode | ❌ | MIDI-кью (CoreMIDI), выдача таймкода (LTC / MTC) |
| Group: Timeline | ✅ | мультитрек: сдвиг, обрезка, прилипание; срезы на дорожке ⚠ |
| Group: Playlist (crossfade, loop, shuffle) | ✅ | — |
| Group: Start first and enter / go to next, Random | ✅ | — |
| Start, Stop, Pause, Load, Reset, GoTo, Target, Arm, Disarm, Devamp | ✅ | — |
| Wait, Memo | ✅ | — |
| Script (AppleScript) | ❌ | по запросу |

## Запуск и управление

| QLab 5 | Qtrl | Что сделать |
|---|---|---|
| Hotkey-триггер кью | ✅ | — |
| MIDI-триггер кью, MIDI-управление GO/Stop | ❌ | CoreMIDI |
| OSC-управление QLab (/go, /stop, /cue/N/start …) | ❌ | OSC-сервер Qtrl с командами QLab |
| Wall clock (время суток), таймкод-триггер | ❌ | — |
| Load to time (⌘T), Preview (V), Audition-выход | 🟡 | ✅ ⌘T для аудио-кью; осталось: группы, отдельный выход прослушивания |
| Autoload, «Load» перед GO | 🟡 | autoload |
| Double-GO protection, Panic duration | ✅ | — |

| QLab 5 | Qtrl | Что сделать |

| Effects (Audio Units) на кью / выходе | ❌ | AU-эффекты |

## Порядок работ

1. Релиз 1.2.1: новый экран, мультитрек группы, сочетания клавиш, исправления воспроизведения.
2. 1.3: правка в строке, колонка «Цель», ⌘F, ⌘T Load to time, autoload, кроссфейд плейлиста, фейд-кью (абсолютный /
   относительный, кривые, стоп цели), срезы аудио, Carts.
3. 1.4: MIDI-кью и MIDI/OSC-управление Qtrl как QLab, таймкод, wall clock, Mic-кью, AU-эффекты, Paste properties.
4. Видео / камера / текст / свет — после решения владельца.
